🎯 THE CORRECTED LOGIC
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INPUT:    ML Prediction (Market Selling Price)
          └─ XGBoost model trained on used car resale prices

DERIVATION:
          marketPrice       = ML Output (clamped ₹100k - ₹50L)
          insuranceValue    = marketPrice × 0.85  (IRDA standard)
          baseValue         = marketPrice × 0.80  (Conservative)
          residualValue     = marketPrice × 0.70  (3-year projection)
          distressValue     = marketPrice × 0.75  (Quick sale)
          salvageValue      = marketPrice × 0.20  (Scrap/parts)

VALIDATION:
          ✅ salvageValue           < residualValue          < distressValue
          ✅ residualValue          < baseValue               < marketPrice
          ✅ insuranceValue         ≤ marketPrice            (slightly below)
          ✅ All values > 0         (no negative prices)
          ✅ Logical consistency maintained

EXTREME HANDLING:
          • High mileage (300k+ km)      → 40% price penalty
          • Negative predictions          → Default ₹100,000
          • Extreme prices (>₹50L)        → Clamped to max
          • ML service failure            → Fallback ₹800,000
